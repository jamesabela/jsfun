Hero Name Badge

One variable

Comic briefing
My badge still says question marks.
Put the variable inside braces and add f before the string.

What you will learn

Use an f-string to place one variable inside a message.

An f-string starts with the letter f. Python replaces anything inside braces with its current value.

Your mission

Replace the question marks so the program prints the hero name stored in hero_name.

Code pattern

hero_name = "Nova"
print(f"Hero name: {hero_name}")

Mission checklist

  • Keep the f before the opening quote.
  • Put hero_name inside braces.
  • Keep the words Hero name: in the message.

Common bug

Without the f, Python prints the braces and variable name as ordinary text.

Run the code, test it, then unlock the next comic mission.
