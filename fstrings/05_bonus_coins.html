F-String Comic Academy - Level 5 of 10

Bonus Coins

Expressions in braces

Comic briefing
The player collected coins and then found a bonus chest.
Python can calculate inside the braces.

What you will learn

Use a simple calculation inside an f-string.

Braces can contain a short Python expression. Python calculates coins + bonus before placing the answer in the message.

Your mission

Print the total number of coins by adding coins and bonus inside the f-string.

Code pattern

apples = 3
oranges = 2
print(f"You have {apples + oranges} fruits.")

Mission checklist

  • Use coins + bonus inside braces.
  • Do not type a fixed total.
  • End the sentence with a full stop.

Common bug

Keep expressions short. Longer calculations are usually clearer when stored in a separate variable.
