Win Rate Display

Percentage formatting

Comic briefing
The game stores 0.75 but players expect 75.0%.
The format code :.1% converts the decimal to a percentage.

What you will learn

Format a decimal as a percentage.

The format code :.1% multiplies the value by 100, shows one decimal place and adds the percent sign.

Your mission

Calculate wins divided by games and display the result as a percentage with one decimal place.

Code pattern

completion = 1 / 2
print(f"Completed: {completion:.1%}")

Mission checklist

  • Calculate win_rate before printing.
  • Use :.1% inside the braces.
  • Use the player name in the message.

Common bug

Do not multiply by 100 as well as using %. The percentage format already does that.

Run the code, test it, then unlock the next comic mission.
