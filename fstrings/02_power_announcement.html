F-String Comic Academy - Level 2 of 10

Power Announcement

Several variables

Comic briefing
A hero needs a dramatic entrance.
One f-string can use several variables.

What you will learn

Place several variables inside one f-string.

Each pair of braces can contain a different variable. Python builds one complete sentence from the text and values.

Your mission

Write one f-string that announces the hero, city and power.

Code pattern

villain = "Dr. Bug"
base = "Mainframe"
weapon = "malware"
print(f"{villain} attacks the {base} using {weapon}!")

Mission checklist

  • Use hero, city and power.
  • Use one print statement.
  • Match the punctuation shown in the mission.

Common bug

Do not place quotation marks around a variable inside the braces.

Run the code, test it, then unlock the next comic mission.
