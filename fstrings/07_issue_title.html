F-String Comic Academy - Level 7 of 10

Comic Issue Title

Methods in braces

Comic briefing
Comic titles need to look bold.
A string method can run inside the braces.

What you will learn

Call a simple string method inside an f-string.

The expression name.upper() creates an uppercase version of the name. The original variable is not changed.

Your mission

Display the hero name in uppercase followed by the issue number.

Code pattern

title = "The Awakening"
print(f"{title.upper()} - PART 1")

Mission checklist

  • Use hero.upper() inside braces.
  • Use the issue variable.
  • Include a hyphen and the word ISSUE.

Common bug

Remember the brackets in upper(). Without them, Python refers to the method instead of running it.

Run the code, test it, then unlock the next comic mission.
