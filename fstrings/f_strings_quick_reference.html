F-String Quick Reference

A one-page reminder

Basic pattern

name = "Aisha"
print(f"Hello {name}")

Several values

score = 90
level = 4
print(f"Score {score} - Level {level}")

Calculation

coins = 12
bonus = 5
print(f"Total: {coins + bonus}")

Two decimal places

price = 7.5
print(f"${price:.2f}")

Percentage

rate = 3 / 4
print(f"{rate:.1%}")

Remember

  • Add f before the opening quote.
  • Put variables inside braces.
  • Use a plain string when there are no values to insert.
