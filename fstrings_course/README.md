# F-String Comic Academy

A ten-level beginner Python course for Python Code Lab. Students learn to use f-strings through short comic-themed missions featuring Byte and Pixel.

## Learning goals

Students will learn to:

- insert one or more variables into a string
- combine input values with messages
- display integers without calling `str()`
- use short expressions inside braces
- format money to two decimal places
- use a string method inside braces
- format a decimal as a percentage
- identify and repair a missing `f`
- decide when a plain string is clearer than an f-string

## Includes

1. `01_hero_name.py` and `01_hero_name.html` - Use an f-string to place one variable inside a message.
2. `02_power_announcement.py` and `02_power_announcement.html` - Place several variables inside one f-string.
3. `03_gamer_status.py` and `03_gamer_status.html` - Combine input values with an f-string.
4. `04_score_alert.py` and `04_score_alert.html` - Display an integer inside a message.
5. `05_bonus_coins.py` and `05_bonus_coins.html` - Use a simple calculation inside an f-string.
6. `06_comic_shop_bill.py` and `06_comic_shop_bill.html` - Format a money value to two decimal places.
7. `07_issue_title.py` and `07_issue_title.html` - Call a simple string method inside an f-string.
8. `08_win_rate.py` and `08_win_rate.html` - Format a decimal as a percentage.
9. `09_fix_the_message.py` and `09_fix_the_message.html` - Find and fix a common f-string error.
10. `10_comic_generator.py` and `10_comic_generator.html` - Build a short text comic using inputs, variables and several f-strings.

Additional files:

- `index.html` - visual course landing page
- `f_strings_quick_reference.html` - one-page student reference
- `comic_style.css` - shared responsive comic design
- `teachers.md` - teacher guide and answer key
- `solutions/` - separate Python answer files
- `validation_report.txt` - automated package checks

## Suggested use

Each mission should take about 5-10 minutes. The full course can be used as one lesson, two shorter lessons or independent revision. Students should run their code before using Run Tests so they can read and interpret their own output.
