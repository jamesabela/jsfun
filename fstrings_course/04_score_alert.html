F-String Comic Academy - Level 4 of 10

Score Alert

Numbers in messages

Comic briefing
The tournament screen needs a score alert.
F-strings can display numbers without using str().

What you will learn

Display an integer inside a message.

The score is converted to an integer for calculations. An f-string displays it automatically, so str(score) is not needed.

Your mission

Print a score alert using the player name and integer score.

Code pattern

score = int(input("Score: "))
print(f"You scored {score} points!")

Mission checklist

  • Convert the score using int().
  • Use both variables.
  • Include the word points and an exclamation mark.

Common bug

Do not join text and an integer with +. That causes a TypeError unless the number is converted first.
