Gamer Status

Input and f-strings

Comic briefing
Players want a status message about their favourite game.
Save each answer first, then use both variables in the f-string.

What you will learn

Combine input values with an f-string.

input() returns text. Store each answer in a variable and then place the variables inside braces.

Your mission

Ask for a name and favourite game. Print the status in the exact format shown.

Code pattern

name = input("Name: ")
game = input("Game: ")
print(f"{name} plays {game}.")

Mission checklist

  • Use both input variables.
  • End the sentence with a full stop.
  • Do not type a fixed name or game.

Common bug

Writing {input(...)} directly can make the program hard to read. Clear variable names are better here.
