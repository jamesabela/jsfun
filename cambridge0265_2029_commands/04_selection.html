Level 4 - Selection

if, elif and else

Use selection when a program needs to choose between different actions.

Commands to know

ifelifelse

Example

score = int(input("Score: "))
if score >= 80:
    print("Gold")
elif score >= 60:
    print("Silver")
else:
    print("Bronze")
