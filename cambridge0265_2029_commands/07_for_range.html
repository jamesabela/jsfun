Level 7 - Iteration

for Loops and range()

Students should recognise all three common forms of range(), as well as looping directly through a list.

Commands to know

forrange(stop)range(start, stop)range(start, stop, step)

Example

for i in range(4):
    print(i)
for i in range(2, 6):
    print(i)
for i in range(10, 4, -2):
    print(i)
names = ["Aisha", "Ben"]
for name in names:
    print(name)

Your task

Use range(start, stop, step) to print 10, 8, 6, 4, 2. Then use a second for loop to print each name in the supplied list.
