Level 9 - Lists

List Analysis

Lists store several values under one variable name. Students should analyse them using built-in functions and membership tests.

Commands to know

[]list[index]sum()max()min()len().count()innot in

Example

scores = [12, 18, 18, 15]
print(scores[0])
print(sum(scores))
print(max(scores))
print(min(scores))
print(len(scores))
print(scores.count(18))
print(15 in scores)
print(99 not in scores)

Your task

Use the supplied list to print the first score, total, highest, lowest, length, how many 18s there are, and whether 15 is present.

Tip: Run the program often. Read error messages carefully and use the tests when you think the task is complete.
