# Cambridge 0265 Python Commands - 2029

A focused Python Code Lab course for the Python commands and syntax students need for Cambridge IGCSE Computer Science 0265 from 2029.

## Course levels
1. **Variables, Input and Output** - =, +=, int, float, str, bool, True, False, input(), print(), # comment
2. **Arithmetic Operators** - +, -, *, /, //, %, **
3. **Comparisons and Boolean Logic** - ==, !=, <, <=, >, >=, and, or, not
4. **if, elif and else** - if, elif, else
5. **match and case** - match, case, case _, |
6. **while Loops and break** - while, while True, break
7. **for Loops and range()** - for, range(stop), range(start, stop), range(start, stop, step)
8. **String Methods, Indexing and Slicing** - len(), .find(), .count(), .upper(), .lower(), .title(), .replace(), +, [0], [-1], [start:end]
9. **List Analysis** - [], list[index], sum(), max(), min(), len(), .count(), in, not in
10. **Editing and Sorting Lists** - .append(), .insert(), .pop(), .sort(), .sort(reverse=True)
11. **2D Lists and Nested Loops** - list[row][column], nested for loops
12. **Functions, Parameters and return** - def, parameters, arguments, return, function call
13. **Global Variables** - global, +=
14. **Random, Statistics and Rounding** - import random, random.randrange(), random.randint(), import statistics, statistics.mean(), round()
15. **Reading Text Files** - open(), "r", .read(), .readline(), .readlines(), .close(), with open(...) as ...
16. **Writing and Appending Files** - "w", "a", .write(), with open(...) as ...
17. **Final Structured Challenge** - input, list, for, def, return, if/elif/else, statistics.mean, round, max, min
