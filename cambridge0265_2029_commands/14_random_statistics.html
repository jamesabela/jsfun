Level 14 - Modules

Random, Statistics and Rounding

The syllabus names random and statistics. Students should know the specified functions and how to round results.

Commands to know

import randomrandom.randrange()random.randint()import statisticsstatistics.mean()round()

Example

import random
import statistics
scores = [10, 11, 14]
print(round(statistics.mean(scores), 2))
print(random.randint(1, 6))
print(random.randrange(0, 10, 2))

Your task

Calculate and print the mean of the supplied scores rounded to 1 decimal place. Then generate a random die roll from 1 to 6 and a random even number from 2 to 10 using randrange().

Tip: Run the program often. Read error messages carefully and use the tests when you think the task is complete.
