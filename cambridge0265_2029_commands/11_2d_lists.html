Level 11 - Lists

2D Lists and Nested Loops

A 2D list is a list containing lists. Students should understand row and column indexing and how nested loops visit every value.

Commands to know

list[row][column]nested for loops

Example

grid = [[2, 4, 6], [1, 3, 5]]
print(grid[0][1])
for row in grid:
    for value in row:
        print(value)

Your task

Use nested loops to total every number in the 2D list. Also print the value at row 1, column 2.

Tip: Run the program often. Read error messages carefully and use the tests when you think the task is complete.
