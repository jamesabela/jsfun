Cambridge 0265 Command Matrix

The course is strictly limited to the official Cambridge 0265 Python subset for 2029 examinations.

Topic Area Python Commands
Assignment =, +=
Types & Values int, float, str, bool, True, False
Input / Output input(), print()
Casting int(), float(), str()
Comments # comment
Arithmetic +, -, *, /, //, %, **
Comparison ==, !=, <, <=, >, >=
Boolean Logic and, or, not
Selection if, elif, else, match, case, case _, |
Iteration for, while, range(), break
Strings len(), .find(), .count(), .upper(), .lower(), .title(), .replace(), +, [0], [-1], [start:end]
Lists [], [idx], 2D [r][c], sum(), max(), min(), len(), .count(), .append(), .insert(), .pop(), .sort(), in, not in
Functions def, parameters, arguments, return, function calls
Statistics import statistics, statistics.mean(), round()
Random import random, random.randrange(), random.randint()
Scope global
Files open(), with open(...) as ..., "r", "w", "a", .close(), .read(), .readline(), .readlines(), .write()
Exclusions: Deliberately NOT on 0265: Dictionaries, tuples, sets, classes, OOP, exception handling (try/except), lambdas, list comprehensions, recursion, enumerate(), zip(), continue, or f-strings.
