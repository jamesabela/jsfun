Level 16 - Files

Writing and Appending Files

Write mode creates or replaces file contents. Append mode adds new content to the end of a file.

Commands to know

"w""a".write()with open(...) as ...

Example

with open("result.txt", "w") as file:
    file.write("Aisha,18\n")

with open("result.txt", "a") as file:
    file.write("PASS\n")

Your task

Input a name and score. Write name,score to result.txt using write mode. Then append PASS on a new line. Reopen the file and print its contents.
