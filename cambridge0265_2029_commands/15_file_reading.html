Level 15 - Files

Reading Text Files

File reading lets a program use stored data. This level shows both explicit open and close and the safer with open pattern.

Commands to know

open()"r".read().readline().readlines().close()with open(...) as ...

Example

file = open("scores.txt", "r")
text = file.read()
file.close()

with open("scores.txt", "r") as file:
    first = file.readline()
    rest = file.readlines()
