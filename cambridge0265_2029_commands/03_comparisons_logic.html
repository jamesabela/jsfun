Level 3 - Operators

Comparisons and Boolean Logic

Comparisons produce Boolean results. Logical operators let you combine conditions into rules.

Commands to know

==!=<<=>>=andornot

Example

age = 15
member = True
print(age >= 13 and age <= 17)
print(age == 15 or member)
print(not member)
print(age != 18)

Your task

Input an age. Print whether it is between 13 and 17 inclusive, whether it is not 16, and whether it is younger than 13 or older than 17.

Tip: Run the program often. Read error messages carefully and use the tests when you think the task is complete.
