Level 5 - Selection

match and case

Pattern selection is useful when one value is compared with several exact choices.

Commands to know

matchcasecase _|

Example

ticket = input("Ticket type: ").lower()
match ticket:
    case "elderly" | "student":
        print("Half price")
    case "child":
        print("Child price")
    case _:
        print("Standard price")
