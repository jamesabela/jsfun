# Cambridge 0265 Python Command Checklist - 2029

| Area | Python commands and syntax |
| --- | --- |
| Assignment | `=`, `+=` |
| Types and values | `int`, `float`, `str`, `bool`, `True`, `False` |
| Input and output | `input()`, `print()` |
| Casting | `int()`, `float()`, `str()` |
| Comments | `# comment` |
| Arithmetic | `+`, `-`, `*`, `/`, `//`, `%`, `**` |
| Comparison | `==`, `!=`, `<`, `<=`, `>`, `>=` |
| Logic | `and`, `or`, `not` |
| Selection | `if`, `elif`, `else`, `match`, `case`, `case _` |
| Iteration | `for`, `while`, `range()`, `break` |
| Strings | `len()`, `.find()`, `.count()`, `.upper()`, `.lower()`, `.title()`, `.replace()`, concatenation, indexing, slicing |
| Lists | `[]`, indexing, 2D indexing, `sum()`, `max()`, `min()`, `len()`, `.count()`, `.append()`, `.insert()`, `.pop()`, `.sort()`, `in`, `not in` |
| Functions | `def`, parameters, arguments, `return`, function calls |
| Statistics | `import statistics`, `statistics.mean()`, `round()` |
| Random | `import random`, `random.randrange()`, `random.randint()` |
| Scope | `global` |
| Files | `open()`, `with open(...) as ...`, `"r"`, `"w"`, `"a"`, `.close()`, `.read()`, `.readline()`, `.readlines()`, `.write()` |

## Deliberately not part of this course

This course does not teach dictionaries, tuples, sets, classes, exception handling, lambdas, comprehensions, recursion, `enumerate()`, `zip()`, `continue` or f-strings.
