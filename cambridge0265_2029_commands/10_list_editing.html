Level 10 - Lists

Editing and Sorting Lists

Students need to add, insert, remove and sort items in a list.

Commands to know

.append().insert().pop().sort().sort(reverse=True)

Example

names = ["Ben", "Chen"]
names.append("Dina")
names.insert(0, "Aisha")
removed = names.pop(1)
names.sort()
names.sort(reverse=True)

Your task

Start with [5, 2, 9]. Append 4, insert 7 at index 1, remove the item at index 2 with pop(), then sort descending. Print the removed value and final list.

Tip: Run the program often. Read error messages carefully and use the tests when you think the task is complete.
