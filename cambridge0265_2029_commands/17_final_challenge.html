Final Structured Challenge

The final level combines several commands in one structured programming task. The aim is to select the right Python tools rather than memorise isolated syntax.

Commands to know

inputlistfordefreturnif/elif/elsestatistics.meanroundmaxmin

Example

def band(score):
    if score >= 80:
        return "High"
    elif score >= 50:
        return "Medium"
    else:
        return "Low"

Your task

Input three scores. Store them in a list. Write a function classify(score) returning High for 80+, Medium for 50-79 and Low below 50. Print the rounded mean, highest, lowest and classification of the highest score.

Tip: Run the program often. Read error messages carefully and use the tests when you think the task is complete.
