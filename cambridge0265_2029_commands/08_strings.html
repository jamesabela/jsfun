Level 8 - Strings

String Methods, Indexing and Slicing

String questions use real Python operations. Students need both methods and index or slice notation.

Commands to know

len().find().count().upper().lower().title().replace()+[0][-1][start:end]

Example

text = "python programming"
print(len(text))
print(text.find("pro"))
print(text.count("m"))
print(text.upper())
print(text.lower())
print(text.title())
print(text.replace("python", "coding"))
print(text[0])
print(text[-1])
print(text[0:6])
