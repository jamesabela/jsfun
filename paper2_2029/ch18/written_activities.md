# Timed written review

Allow 12 minutes.

1. Explain why meaningful identifiers improve maintainability. [2]
2. Give the difference between the purpose of an algorithm and the trace of one execution. [2]
3. Explain why a descending binary search sends a larger target to the left half. [2]
4. State two checks to make when converting a repeated-input flowchart into Python. [2]
5. Explain why a joined SQL count may count students rather than clubs. [2]

## Model answers

1. The name identifies what the value represents, making later code changes easier to understand.
2. Purpose describes the overall task; a trace records actual instructions and values for particular inputs.
3. In descending order, values larger than the middle are on its left, so that half may contain the target.
4. Check initialisation before repetition and re-input/update inside repetition; also accept matching exit condition and correct output placement.
5. One club can join to several student records, producing one matching row per student. Count the entity the question asks for.
