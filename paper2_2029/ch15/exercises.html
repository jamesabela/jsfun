Use a fresh database created by setup.sql. Tasks 1-7 use the original data. Task 8 changes it. The CREATE TABLE and PRAGMA setup are practical infrastructure, not additional required exam commands.

1. Select fields

List club names and fees, ordered by name.

2. Inclusive filter

List names of clubs with capacity at least 15, ordered by name.

3. Two conditions

List names with capacity at least 15 AND fee below 7.

4. Descending order

List club names and fees, highest fee first.

5. Count records

Count students choosing C01.

6. Sum values

Find the total capacity of all clubs.

7. Join and filter

List only names and tutor groups of students choosing Coding, ordered by name.

8. Insert a record

Add S05, Eli, 9B, C02, then count students choosing Art.

Use a fresh SQLite database in your database tool. Run the setup below, then attempt the exercises.

Database setup SQL
PRAGMA foreign_keys = ON;
CREATE TABLE CLUB (
 ClubID TEXT PRIMARY KEY NOT NULL,
 ClubName TEXT NOT NULL,
 Capacity INTEGER NOT NULL CHECK(Capacity > 0),
 Fee NUMERIC NOT NULL CHECK(Fee >= 0)
);
CREATE TABLE STUDENT (
 StudentID TEXT PRIMARY KEY NOT NULL,
 StudentName TEXT NOT NULL,
 TutorGroup TEXT NOT NULL,
 ClubID TEXT NOT NULL REFERENCES CLUB(ClubID)
);

SQL model answers

SQL teacher answers

1. Select fields

SELECT ClubName, Fee FROM CLUB ORDER BY ClubName ASC;

Expected result: [('Art', 8), ('Coding', 5), ('Music', 6.5)].

2. Inclusive filter

SELECT ClubName FROM CLUB WHERE Capacity >= 15 ORDER BY ClubName ASC;

Expected result: [('Art',), ('Coding',)].

3. Two conditions

SELECT ClubName FROM CLUB WHERE Capacity >= 15 AND Fee < 7;

Expected result: [('Coding',)].

4. Descending order

SELECT ClubName, Fee FROM CLUB ORDER BY Fee DESC;

Expected result: [('Art', 8), ('Music', 6.5), ('Coding', 5)].

5. Count records

SELECT COUNT(*) FROM STUDENT WHERE ClubID = 'C01';

Expected result: [(2,)].

6. Sum values

SELECT SUM(Capacity) FROM CLUB;

Expected result: [(47,)].

7. Join and filter

SELECT STUDENT.StudentName, STUDENT.TutorGroup FROM STUDENT INNER JOIN CLUB ON STUDENT.ClubID = CLUB.ClubID WHERE CLUB.ClubName = 'Coding' ORDER BY STUDENT.StudentName ASC;

Expected result: [('Aisha', '9A'), ('Chen', '9A')].

8. Insert a record

INSERT INTO STUDENT (StudentID, StudentName, TutorGroup, ClubID) VALUES ('S05','Eli','9B','C02');

Expected result: [(2,)].
