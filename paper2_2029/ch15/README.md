# Chapter 15 - SQL practice

These queries are SQL, not Python Code Lab programs. Open a fresh SQLite database in a suitable database tool and run setup.sql, then attempt exercises.md. See teachers.md for queries and results. Use ASC and DESC for executable ordering syntax.

The optional verify_sql.py runs the reference queries locally with Python's standard sqlite3 module: `python verify_sql.py`. It creates independent in-memory databases, so it does not overwrite a user's existing database. Database creation syntax and Python sqlite3 are setup tools, not extra syllabus requirements.
