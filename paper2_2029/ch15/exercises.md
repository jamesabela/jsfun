# SQL practice

Use a fresh database created by setup.sql. Tasks 1-7 use the original data. Task 8 changes it. The CREATE TABLE and PRAGMA setup are practical infrastructure, not additional required exam commands.

## 1. Select fields
List club names and fees, ordered by name.

## 2. Inclusive filter
List names of clubs with capacity at least 15, ordered by name.

## 3. Two conditions
List names with capacity at least 15 AND fee below 7.

## 4. Descending order
List club names and fees, highest fee first.

## 5. Count records
Count students choosing C01.

## 6. Sum values
Find the total capacity of all clubs.

## 7. Join and filter
List only names and tutor groups of students choosing Coding, ordered by name.

## 8. Insert a record
Add S05, Eli, 9B, C02, then count students choosing Art.
