Descending bubble sort

Searching and Sorting

Learn and predict

A linear search checks each value in sequence. Bubble sort compares adjacent values, swaps those in the wrong order and repeats passes until the list is ordered. Predict the output for the first test before running your program.

Teacher review must confirm adjacent comparisons, repeated passes and swaps.

Try

Input four integers, bubble-sort them in descending order and print one value per line. Do not use .sort().

values = []
for index in range(4):
    values.append(int(input("Value: ")))
# Add repeated bubble passes.
