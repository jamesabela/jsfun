LEVEL 7: SELECTION

Selection with strings

Strings can be compared using ==.

Task

Fix the comparison so entering yes prints Continuing.

answer = input("Continue? ")
if answer = "yes":
    print("Continuing")
else:
    print("Stopping")

Hint

Comparison uses two equals signs.
