LEVEL 3: SELECTION

Using elif

elif lets Python test another condition if earlier conditions were False.

Task

Fix the order of the conditions so 80 or more is Excellent, 50 to 79 is Pass, and lower scores are Not yet passed.

if score >= 50:
    print("Pass")
elif score >= 80:
    print("Excellent")
else:
    print("Not yet passed")

Hint

Python stops after the first True branch.
