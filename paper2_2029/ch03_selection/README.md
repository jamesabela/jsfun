# Selection and Decisions - Python Code Lab Course

This course supports Chapter 3 of the 2029 Cambridge IGCSE Computer Science Paper 2 book.

## Includes

1. level1_if.py - simple if and boundary values
2. level2_else.py - two-way selection
3. level3_elif.py - multiple conditions and condition order
4. level4_and_or.py - combining conditions
5. level5_not.py - reversing a Boolean condition
6. level6_nested.py - nested selection
7. level7_strings.py - string comparison
8. level8_match.py - match-case and default cases
