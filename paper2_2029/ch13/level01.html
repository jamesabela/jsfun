Repair a total

Testing, Errors and Debugging

Learn and predict

A test needs an independently predicted result. Boundary values expose comparison mistakes. A program can run successfully and still contain a logic error. Predict the output for the first test before running your program.

Try

The code adds indices instead of entered scores. Correct it to input three integers and display Total:.

total = 0
for index in range(3):
    value = int(input("Score: "))
    total = total + index
print("Total:", total)

First test

Inputs in order: ['8', '2', '5']

Total: 15

Change and explain

After passing, choose another suitable input or change one fixture value. Predict and check the new result. Explain which instruction controls it. Keep a copy of the original version for the supplied tests.
