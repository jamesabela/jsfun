Add and insert

Lists and 2D Lists

Learn and predict

List indices begin at zero. append adds, insert shifts later items, and pop removes and returns an indexed item. For 2D data, the row index comes before the column index. Predict the output for the first test before running your program.

Try

Append Dina to the supplied list, then insert Ben at index 1. Print every name on a separate line.

names = ["Aisha", "Chen"]
# Use append and insert.

Ben
Chen
Dina

Change and explain
