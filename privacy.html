JSFUN · YOUR PRIVACY

Privacy Notice

Last updated: 16 November 2026

Learn without a JSFun account.

JSFun prioritises processing in your browser and minimising information sent elsewhere. Some tools save work on your device. Hosting, external libraries, remote files and embedded content still involve network requests. Basic analytics is off unless you choose to allow it.

Who runs JSFun?

JSFun is a free educational project maintained by James Abela. For questions about privacy or to make a data protection request, use the contact form (Google Forms).

Information and student work

The reviewed code does not provide JSFun registration or a central database for student submissions. Text, code, answers, names entered into classroom tools and uploaded files may be processed in the browser. Avoid entering real names, sensitive information or identifiable student records when they are unnecessary.

Python Code Lab can keep an activity history, including code changes, timings and optional feeling or frustration responses, in page memory. Downloaded activity logs contain this information. They are not automatically sent to James; sharing an export with a teacher or another service is a separate action. Downloaded files remain wherever you save them.

Browser storage and shared devices

Tools use localStorage and sessionStorage for features such as drafts, progress, preferences and transferring work between tools. Python Code Lab also caches application files for offline use. Local storage can survive closing the browser; session storage normally ends when the tab’s session ends. Browser eviction or private browsing can remove data sooner. Other people using the same browser profile may see saved work.

Use a tool’s delete or reset option where available. To remove remaining saved data, first download anything you need, then open your browser’s site-data settings and clear data for jamesabela.github.io. This can remove work, preferences and offline files for other projects on the same origin. It does not delete downloads or copies shared elsewhere. Clearing the analytics preference returns it to off.

Sharing links and external services

Some share links contain the actual text, code or diagram, rather than a private reference to it. Anyone with the link may be able to read that content. URLs may appear in browser history, messages and provider logs. Check links and exported files before sharing them; do not put personal information in them.

Some tools load code and styling from providers such as jsDelivr, cdnjs/Cloudflare and unpkg. Remote examples can come from GitHub/Gist or a URL you supply. Python Code Lab routes Pastebin requests through corsproxy.io, which receives the requested URL and handles the returned content. These providers receive network information such as your IP address and browser headers. A URL you provide can contain identifying information.

External embedded content on lesson pages loads after you select its load button. Python Code Lab also offers external page previews; these contact the selected provider. YouTube, Google Slides, externally hosted images, AI tools and classroom-sharing services have their own privacy terms. Visiting an AI link does not itself upload your work; anything you paste or submit there is handled by that service. Referrer information is suppressed by these pages where the browser honours the policy.

GoatCounter analytics

If you allow analytics, JSFun sends GoatCounter a fixed page identifier to count use of educational resources. The integration omits your page’s query string, fragment, title, referring page, screen size and entered content, and requests no session tracking. It does not load GoatCounter’s external JavaScript. The network request still exposes your IP address and browser headers to the provider; dashboard settings can affect information derived from them. See GoatCounter’s privacy policy.

Your analytics choice

Optional statistics help James understand which tools are used. You can use every tool without allowing analytics. Your choice applies across JSFun tools in this browser on the same website address, until you change it or clear site data. It does not carry across devices. Do Not Track and Global Privacy Control signals also prevent counting.

Analytics is off by default. JavaScript is needed to save a choice.

Turning analytics off stops future counts; it does not retract statistics already sent.

Hosting and security logs

GitHub Pages delivers this website. Hosting requests can expose your IP address, browser information and requested URL, including query strings, to GitHub and its infrastructure. These requests are needed even when analytics is off. See the GitHub General Privacy Statement for its processing and retention practices.

Purposes and lawful bases

Processing supports requested learning tools, saving preferences, delivering and securing the site, and optional usage statistics. The analytics control asks for your permission before sending a count. James must confirm the applicable legal bases and any requirements for children’s consent before publication. Legitimate interests may be relevant to delivery and security, subject to an assessment; it is not asserted here as an approved basis. GDPR lawful bases and ePrivacy or UK PECR storage/access rules require separate consideration. Cookieless does not automatically mean consent-free.

Retention and international transfers

Browser data lasts as described above. GoatCounter is configured to automatically delete pageview statistics and associated analytics data after 365 days. Hosting-log retention has not been independently verified. Provider policies describe their own practices. Providers may process information outside your country, including outside Malaysia, the UK or the EEA. GoatCounter states that its hosted data is stored in Finland and Germany. Contractual roles, applicable transfer safeguards and arrangements for other providers still need confirmation; this notice does not promise arrangements that have not been checked.

Children, teachers and parents

Use fictional names and non-sensitive examples. On shared devices, save needed files and remove local work after use. Teachers and parents should check external resources and sharing destinations before children use them, and agree how exported learning records will be handled. Optional analytics is not required for learning.

Your rights, contact and complaints

Depending on the law that applies, you may have rights to access, correct or delete personal information, restrict or object to processing, receive portable data, and withdraw consent. These rights have conditions and exceptions. Information kept only in your browser cannot be retrieved remotely by James.

Contact James using the privacy enquiry form (Google Forms). The form opens a separate Google service; Google’s privacy policy applies. Provide only the information needed to explain your request. James uses the details you submit to respond to your enquiry; the retention period for correspondence is still to be confirmed. Do not put student data or private requests into public GitHub issues. For general project information, see the JSFun repository.

You can complain to the relevant supervisory authority, such as the UK Information Commissioner’s Office, your EEA data protection authority or Malaysia’s Personal Data Protection Commissioner. You do not have to use a public project forum to exercise your rights.
