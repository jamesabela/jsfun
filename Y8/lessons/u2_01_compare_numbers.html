Comparing Two Numbers (Example)

PredictRunModify
What happens when both numbers are the same? Fix a classic logic bug using elif!
Your Mission
  1. Run: Test the starter code with 24 and 12, then test with 10 and 10.
  2. Modify: Change the code so it uses input() for both numbers and prints Values are the same when they are equal.
Key Pattern
if num1 > num2:
    print(num1)
elif num2 > num1:
    print(num2)
else:
    print("Values are the same")
👀 Predict First! Click to check what happens

With only if / else, equal numbers fall into else and falsely claim the second number is bigger!

💡 Stuck? Common Bug Hint

Use elif num2 > num1: for the second check and else: for when they are equal.
