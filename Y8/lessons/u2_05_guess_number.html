Guess the Secret Number (1–10)

Make
Use Python's random module to build a mini guessing game!
Your Mission
  1. Import random and generate number = random.randint(1, 10).
  2. Ask the user to guess a number from 1 to 10.
  3. If guess == number, print Correct. Otherwise, print Not what I was thinking.
Key Pattern
import random
number = random.randint(1, 10)
👀 Predict First! Click to check what happens

Each time you run it, random.randint(1, 10) picks a fresh integer from 1 to 10 inclusive.

💡 Stuck? Common Bug Hint

Temporarily print number while testing so you can verify both the win and lose messages!
